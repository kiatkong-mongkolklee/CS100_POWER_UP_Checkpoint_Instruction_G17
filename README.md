# Personal Learning Portfolio
 
A small web app for keeping track of what you've done and what you learned from it. Everything is saved in your browser, so there's no sign-up and no server.
 
# Open it
 
Download or clone the repo, then double-click **`index.html`**. It opens in your browser. (You need internet the first time, since Bootstrap and the font load from a CDN.)
 
# How to use
 
1. Choose a portfolio in the Select Portfolio dropdown (Portfolio 1 or Portfolio 2).
2. Fill in your profile: display name, what you enjoy, what you've tried, and what you're curious about.
3. Fill in an item (a project, course, activity, etc.): title, type, date, role, description, skills, the four reflection answers, and an evidence link.
- Separate several skills or links with commas, like `HTML, CSS`.
- If you pick the type **Other**, type your own.
4. Press Create Portfolio. A green message appears and your item shows up under View Portfolio.
5. To add more, fill in another item and press the button again. Switch the dropdown to make a second portfolio.
6. Clear empties the form.
If something is missing or wrong (empty field, bad date, link not starting with `http://` or `https://`), the field turns red with a message and nothing is saved until you fix it.
